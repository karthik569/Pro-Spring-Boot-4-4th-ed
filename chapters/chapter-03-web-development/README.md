# Chapter 3: Web Development with Spring Boot

This directory contains the source code for Chapter 3 of the book "Pro Spring Boot 4".

## Learning Objectives
- Evolve a simple REST API into a robust, production-ready service.
- Explore new features in Spring Boot 4, Spring Framework 7, and Jakarta EE 11 for web development.
- Understand and implement native API versioning.
- Create declarative HTTP clients using `@HttpExchange`.
- Leverage Jackson 3 for JSON processing with Java Records.
- Adopt the unified `RestTestClient` for web layer testing.
- Gain a deep understanding of modern Spring MVC architecture.
- Design maintainable and testable APIs.

## Key Topics
- Spring MVC architecture and request lifecycle
- RESTful API design principles and versioning strategies
- Jakarta EE 11 and Servlet 6.1
- Jackson 3 integration for JSON processing
- Domain model validation with Jakarta Validation 3.1
- Global exception handling with `@ControllerAdvice` and `ProblemDetail` (RFC 7807)
- Content negotiation (JSON, XML)
- Declarative HTTP Clients with `@HttpExchange`
- Unified testing with `RestTestClient`
- GraalVM native image efficiency considerations
