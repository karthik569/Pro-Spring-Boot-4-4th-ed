# Chapter 5: Advanced Data Access with JdbcClient

This directory contains the source code for Chapter 5 of the book "Pro Spring Boot 4".

## Learning Objectives
- Explore the new Spring Framework 6 JDBC Client
- Compare with JdbcTemplate
- Implement fluent API patterns
- Handle complex queries elegantly

## Key Topics
- Introduction to JDBC Client API (Spring Framework 6.1+)
- Fluent query building and execution
- Parameter binding strategies (named parameters)
- Result mapping patterns (automatic mapping to records)
- Refactoring from JdbcTemplate to JdbcClient
- Transaction handling:
  - Declarative transactions with `@Transactional`
  - Concurrency and isolation levels
  - Programmatic transactions with `TransactionTemplate`
- Testing with Mocks and Mockito
- Best practices for JDBC Client usage
