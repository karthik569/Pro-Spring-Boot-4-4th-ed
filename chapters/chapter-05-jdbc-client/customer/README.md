# Chapter 1: Spring Boot - Quick Start

This directory contains the source code for Chapter 1 of the book "Pro Spring Boot 4".

## Learning Objectives
- Understand Spring Boot fundamentals
- Create first Spring Boot application
- Explore auto-configuration magic
- Use Spring Initializr effectively

## Key Topics
- Spring Boot starter dependencies
- Auto-configuration principles
- Application properties and YAML configuration
- Embedded servers (Tomcat, Jetty, Undertow)
- DevTools for rapid development
- Building and running Spring Boot applications
