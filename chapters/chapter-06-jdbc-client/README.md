# Chapter 6: JDBC Client with Spring Boot

This directory contains the source code for Chapter 6 of the book "Pro Spring Boot 4".

## Learning Objectives
- Explore new Spring Framework 6 JDBC Client
- Compare with JdbcTemplate
- Implement fluent API patterns
- Handle complex queries elegantly

## Key Topics
- Introduction to JDBC Client API (Spring Framework 6.1+)
- Fluent query building
- Parameter binding strategies
- Result mapping patterns
- Comparison with JdbcTemplate
- Migration strategies from JdbcTemplate
