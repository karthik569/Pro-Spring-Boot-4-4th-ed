# Chapter 11: Security with Spring Boot

This directory contains the source code for Chapter 11 of the book "Pro Spring Boot 4".

## Learning Objectives
- Implement authentication and authorization
- Secure REST APIs
- Work with OAuth2 and JWT
- Handle CORS and CSRF

## Key Topics
- Spring Security 6 architecture
- Authentication mechanisms (JWT, OAuth2)
- Authorization strategies
- Securing REST APIs
- CORS and CSRF protection
- Password encoding (BCrypt)
- Lambda DSL configuration
