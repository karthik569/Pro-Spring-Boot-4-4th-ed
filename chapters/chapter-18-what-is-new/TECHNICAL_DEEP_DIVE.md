# Technical Deep Dive: Chapter 18 - What is New in Spring Boot 4

## 1. Executive Overview
Chapter 18 synthesizes the major architectural milestones in Spring Boot 4 and Spring Framework 7:
- **Baseline Migration**: Mandatory Java 21 LTS floor.
- **Runtime Evolution**: Default Virtual Threads option, GraalVM AOT maturity, and CRaC checkpoint restore.
- **Data Evolution**: Fluent `JdbcClient` and vector-native database abstractions.
- **Standardized RPC**: Native Spring gRPC 1.0.0.
- **AI Infrastructure**: First-class Spring AI and Model Context Protocol (MCP) ecosystems.
